# 02. 产品需求规格说明书（PRD）

**文档编号**：LUMEN-PRD-2026-02  
**版本**：v1.0.0（定稿）  
**产品名称**：LumenHID — 极简全协议外设驱动中心  
**交付形态**：Windows 10/11 x64 免安装便携版 `.exe`（Tauri v2 构建） + Web 交互式预览端

---

## 1. 产品愿景与设计原则

LumenHID 致力于以“克制、淡雅、精准”的工业设计哲学重构桌面外设驱动体验：
- **极简淡雅视觉**：以低饱和度雾白画布（`#F6F7F9`）、纯白信息卡片（`#FFFFFF`）、1px 细发丝线边框与青瓷灰绿（`#2B6B68`）作为核心点缀色，遵循 60-30-10 色彩配比，摒弃高饱和度霓虹灯效与视觉噪音。
- **丝滑微交互**：页面切换与分段控件指示器采用 `cubic-bezier(0.16, 1, 0.3, 1)` 缓动，所有常规操作反馈控制在 `≤ 200ms`，仅针对 `transform` 与 `opacity` 进行合成层动画，完整尊重系统 `prefers-reduced-motion` 无障碍设置。
- **零侵入便携运行**：免安装、不写系统注册表，用户配置以明文 JSON 存储于可执行文件同级 `LumenHID.data/` 目录，随 U 盘或云盘即拷即走。

## 3. 非功能性需求与性能指标（NFR）

1. **包体与冷启动**：Windows x64 免安装 `.exe` 经 LTO + Strip 优化后控制在 `≤ 15MB`，冷启动至首屏可交互时间 `≤ 600ms`。
2. **内存与 CPU**：空闲驻留内存 `≤ 45MB`，CPU 占用 `< 0.5%`；高频宏调度误差 `≤ 1.5ms`。
3. **无障碍与可读性**：全文正文字体对比度符合 WCAG AA 标准（`≥ 4.5:1`），所有数字指标启用等宽数字对齐（`tabular-nums`），完整支持键盘 Tab 导航与语义化 ARIA 角色。
4. **工程规范化**：全流程覆盖需求、架构、CI/CD 自动化编译与回归测试文档，并在软件内“工程文档”模块可直接查阅与导出。
