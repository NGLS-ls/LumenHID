**文档编号**：LUMEN-RES-2026-01  
**密级 / 状态**：内部评审定稿（v1.0）  
**调研范围**：Windows 桌面端多协议外设驱动（2.4G / 蓝牙 / USB）、键鼠宏与按键定义、磁轴调校及耳机 EQ 声场软件。

## 1. 调研背景与核心痛点

当前桌面外设生态（鼠标、键盘、耳机）普遍呈现“一厂一驱动、一设备一进程”的割裂现状。用户在同时使用不同品牌的 2.4G 鼠标、三模磁轴键盘及蓝牙/2.4G 耳机时，面临以下显著痛点：

1. **资源开销失控**：传统 Electron 或 .NET 大型驱动套件（如主流品牌驱动）安装包动辄 300MB–600MB，后台常驻进程占用 400MB–900MB 内存，且写入大量系统注册表与自启动服务。
2. **协议割裂**：2.4G 接收器、Bluetooth LE GATT 设备与 USB-C 有线 HID 设备通常需要分别切换驱动或配对工具，难以在单一界面下统一查看电量、回报率与板载配置。
3. **视觉与交互过度电竞化**：市面上大多数驱动采用暗黑霓虹、高饱和度 RGB 动效与复杂嵌套卡片，信息密度失衡，日常办公与轻度游戏用户缺乏极简、安静、高效的调校体验。
4. **缺少便携免安装方案**：网吧、比赛现场或跨电脑办公场景中，用户急需双击即用、配置文件跟随目录携带的免安装（Portable）可执行程序。

## 3. 公开常见外设驱动功能聚合清单

通过对 GitHub 开源外设工具（如 `OpenRGB`、`libratbag`、`Solaar`、`VIA`、`EqualizerAPO`）及公开消费级外设驱动协议分析，提炼出覆盖 95% 用户高频刚需的聚合功能清单：

### 3.1 统一连接与设备管理（2.4G / 蓝牙 / USB）
- 自动热插拔枚举（USB HID VID/PID、2.4G Dongle 透传通道、BLE GATT 电池与 HID 服务）。
- 统一电量监控、无线信号强度（dBm）感知、休眠倒计时配置、板载存储槽位（Onboard Profile 1–4）切换。
- JSON 配置文件一键导入/导出，实现多终端配置同步。

### 3.2 鼠标性能与按键重映射
- 1–6 档自定义 DPI（100–30,000 DPI，50 DPI 步进），支持 X/Y 轴独立灵敏度。
- 回报率切换：`125Hz / 250Hz / 500Hz / 1000Hz / 2000Hz / 4000Hz / 8000Hz`。
- 传感器底层参数：静默高度（LOD 0.7mm/1.0mm/2.0mm）、按键防抖延迟（0–16ms）、Motion Sync（移动同步）、直线修正（Angle Snapping）、波纹控制（Ripple Control）。
- 全按键重映射（鼠标功能、键盘按键、多媒体、系统快捷、DPI 循环、自定义宏）。

### 3.3 键盘改键与磁轴调校
- 标准 75% 交互式键位图，支持 3 层布局（默认层 Base / Fn1 功能层 / Game 游戏层）。
- 磁轴/光轴行程控制：全局触发键程 `0.1mm–4.0mm`、Rapid Trigger（快速触发）灵敏度 `0.05mm–2.0mm`、SOCD（Snap Tap 最后输入优先）。
- 全键无冲（NKRO）、游戏模式禁用 Win 键、极简柔和氛围背光控制。

### 3.4 宏工作台（Macro Studio）
- 实时按键与鼠标事件录制、精确到毫秒（ms）的延迟时间轴编辑。
- 批量延迟标准化（固定延迟、倍速缩放、最小化延迟）。
- 4 种触发模式：单次执行、按住循环、切换循环、指定次数重复，支持软件内模拟预演（Dry-Run）。

### 3.5 耳机 10 段 EQ 与 7.1 虚拟声场
- 10 段高精度图示均衡器（`31Hz`–`16kHz`，`-12dB` 至 `+12dB`）及实时平滑频响曲线。
- 场景声学预设（纯净原声、FPS 脚步增强、团队语音清晰、影院低频、监听爵士）与自定义预设保存。
- 7.1 虚拟环绕声场极坐标方位与通道独立增益调节、声场宽度、房间声学混响（干声/录音室/大厅）。
- 麦克风增益、耳返监听（Sidetone）、噪声门阈值（dB）以及游戏/语音混音平衡。

## 4. 调研结论

采用 **Rust + Tauri v2 + React 19 + TypeScript** 技术路线，在保持免安装体积小于 15MB 与极低内存占用的同时，能够通过 Rust 原生调用 `hidapi`、`btleplug` 及 Windows `WASAPI / SendInput` 能力，并结合极简淡雅的工业设计语言，打造新一代轻量级全协议桌面外设驱动中心。
