# 05. 测试计划与回归验证报告

**文档编号**：LUMEN-QA-2026-05  
**版本**：v1.0.0  
**测试覆盖维度**：单元测试（`node:test`）、编译静态检查（`tsc` + `vite build`）、端到端浏览器交互与视觉验收（Playwright）、Windows 便携包回归清单

---

## 1. 测试策略与金字塔模型

1. **L1 单元逻辑测试（自动化阻断门禁）**：针对 `src/utils/deviceEngine.ts` 的 7 大核心计算与协议模块编写确定性断言，毫秒级完成回归。
2. **L2 静态与构建验证**：确保 TypeScript 零类型错误、Vite 生产产物完整、Rust `src-tauri` 模块结构与 GitHub Actions YAML 语法合法。
3. **L3 端到端交互与 UI/UX 验收**：使用无头 Chromium 在标准桌面分辨率（`1440×900`）与移动端视口（`390×844`）执行全链路用户旅程验证，核查控制台零报错、零布局溢出、无障碍语义与动画流畅度。
4. **L4 实机外设硬件在环（HIL）回归**：针对 Windows 10/11 目标环境执行 2.4G Dongle 热插拔、BLE 重连、8000Hz 回报率稳态及免安装目录读写验证。

## 4. Windows 免安装版实机回归检查单（发版前必签）

- [ ] **便携目录隔离**：将 `LumenHID-Portable-win-x64.zip` 解压至非 C 盘只读权限以外的任意中文路径，双击启动后同级生成 `LumenHID.data/`，注册表无新增项。
- [ ] **WebView2 兼容**：在纯净 Windows 10 (21H2+) 与 Windows 11 (23H2/24H2) 上无需管理员权限即可启动主界面。
- [ ] **多协议热插拔**：同时插拔 2.4G Dongle 与 USB-C 数据线，1.5 秒内刷新设备连接状态且不崩溃。
- [ ] **休眠唤醒恢复**：系统 S3 睡眠唤醒后，已配置的 DPI、键盘层与耳机 EQ 仍保持生效。
- [ ] **SHA-256 校验**：发布产物 `LumenHID.exe` 与 GitHub Release 附带的 `SHA256SUMS.txt` 哈希值完全一致。
