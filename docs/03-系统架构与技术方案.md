## 2. 核心技术选型说明

| 层次 | 技术组件 | 选型依据 |
| :--- | :--- | :--- |
| 桌面壳框架 | **Tauri v2** | 复用 Windows 10/11 原生 Edge WebView2，产物体积较 Electron 缩减 90% 以上，天然支持免安装单文件分发 |
| 后端核心语言 | **Rust (Edition 2021)** | 零 GC 停顿保证毫秒级宏触发精度，内存安全且编译后直接产出原生机器码 |
| HID / 2.4G 通信 | **`hidapi` crate** | 跨厂商访问 USB 有线与 2.4G 无线 Dongle 的 HID Input/Output/Feature Report，无需替换系统驱动 |
| 蓝牙协议层 | **Windows WinRT / `btleplug`** | 监听 BLE GATT 电池服务 (`0x180F`) 与 HID over GATT (`0x1812`) 实现统一无线纳管 |

## 3. 免安装（Portable）运行机制设计

为确保 `LumenHID.exe` 真正做到**免安装、零注册表残留、即拷即用**：

1. **便携路径探测逻辑（Rust 侧）**：
   - 程序启动时调用 `std::env::current_exe()` 获取 `.exe` 所在目录 `exe_dir`。
   - 自动检测或创建同级目录 `exe_dir/LumenHID.data/`（包含 `profile.json`、`macros/`、`eq_presets/`）。
   - WebView2 缓存目录通过 `WEBVIEW2_USER_DATA_FOLDER` 环境变量定向至 `exe_dir/LumenHID.data/webview2_cache`，彻底避免污染 `%APPDATA%`。
2. **静态链接与体积极致压缩（`Cargo.toml`）**：
   - 开启 `lto = true`、`codegen-units = 1`、`opt-level = "s"` 与 `strip = true`，剥离调试符号。
   - 启用 `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` 隐藏命令行黑框。

## 4. HID 统一通信协议帧格式（LumenHID Protocol v1）

所有 2.4G 接收器与 USB 有线外设均通过标准化 16 字节 Feature Report 下发配置：

| 字节偏移 | 字段名 | 长度 | 说明 |
| :--- | :--- | :--- | :--- |
| `0x00` | `REPORT_ID` | 1 Byte | 固定 `0x08`（驱动配置通道） |
| `0x01` | `CMD_ID` | 1 Byte | `0x10` 查询状态 / `0x21` 写入 DPI / `0x22` 回报率 / `0x31` 磁轴行程 / `0x41` 写入 10 段 EQ |
| `0x02` | `PAYLOAD_LEN` | 1 Byte | 有效载荷长度（`0..12`） |
| `0x03..0x0E` | `PAYLOAD` | 12 Bytes | 大端序编码参数值（不足补 `0x00`） |
| `0x0F` | `CHECKSUM` | 1 Byte | 前 15 字节按位异或（XOR）校验值，防无线丢包误写 |

## 5. 前端 IPC 契约与浏览器回退机制

`src/services/deviceBridge.ts` 屏蔽了运行环境差异：
- **桌面原生模式**：检测到 `window.__TAURI_INTERNALS__` 时，直接调用 Rust 命令 `scan_devices`、`apply_mouse_config`、`apply_keyboard_config`、`execute_macro`、`apply_audio_eq` 与 `save_portable_profile`。
- **浏览器预览 / WebHID 模式**：无 Tauri 宿主时无缝降级至 WebHID 授权直连 + `localStorage` 本地持久化 + Web Audio API 实时 10 段 BiquadFilter 试听，保证研发评审与交互验证 100% 闭环。
