# 06 厂商私有协议调研与电量适配报告

> 版本：v3.0.0 · 覆盖目标硬件：英菲克 Inphic IN10 (KP 8K)、凌豹 K98PRO 5.0 (USB/2.4G/BLE)、漫步者 HECATE G5 Max

---

## 1. 背景与实测环境

在 Windows 11 真实宿主机与本地官方驱动（`D:\package\INPHIC HUB\INPHIC.exe` 与 `D:\package\tool\HECATE\HECATE.exe`）联合逆向与实测中，LumenHID v2 暴露了三个核心问题：
1. **协议芯片误判与通道未拆封**：
   - 将英菲克 `0x1D57:0xFA65` 误当成 Beken 17 字节协议，导致无法读取真实电量；
   - 复合 HID 设备未按接口与 Usage Page 拆分遥测端点（`telemetry_path`）、控制写端点（`vendor_control_path`）与灯效端点（`led_path`）。
2. **BLE  sibling 节点分裂导致蓝牙电量匹配失效**：
   - Windows PnP 枚举中，蓝牙设备容器实例（如 `BTHLE\DEV_FF0F00191294`，携带 `DEVPKEY_Bluetooth_Battery`）与 HID 子设备实例（如 `BTHLEDEVICE\..._VID&02258A_PID&0040_..._FF0F00191294`）位于不同 PnP 节点，`VID/PID` 与 `DEVPKEY_Bluetooth_Battery` 未自动聚合。
3. **耳机 THX 服务与无驱动键盘缺失安全闭环**：
   - HECATE G5 Max 实际由本地 Windows 服务 `thx_hecate_g5max_service`（TLS HTTP/2 gRPC）提供实时 10 段 EQ 与 7.1 空间声场调校；
   - 凌豹 K98PRO (`VID 0x258A`) 无可公开安全烧录的 Flash 协议表，必须严禁任何 0x258A 硬件写入并改用系统级低风险软驱动引擎。

## 2. 全链路工程化架构（v3.0.0）

### 2.1 防变砖安全护栏与原子快照回滚（`src-tauri/src/safety.rs`）
- **永久硬件只读黑名单**：硬编码永久阻止一切针对中颖电子 `VID 0x258A` 设备的写入操作。
- **高危指令关键词熔断**：拒绝包含 `ota`、`firmware_upgrade`、`bootloader`、`flash_erase` 的写操作。
- **白名单放行**：仅放行已通过逆向及实机校验的 `(0x1D57, 0xFA65)`、`(0x35BB, 0xA00B)`、`(0x35BB, 0xA211)`。
- **全局只读安全锁 (`READONLY_MODE`)**：支持在顶部状态栏与设备总览页一键锁定/解锁，开启后拦截全部 HID 写、THX gRPC 写及键盘低级钩子拦截。
- **写前原子快照**：通过 `.tmp` + 原子 `rename` 将配置与硬件快照持久化到便携目录 `LumenHID.data/backups/<device_key>/`（按设备保留最近 20 份 `pre_write` 快照，并永久保留 `initial_baseline`），支持一键回滚。

### 2.2 Windows 原生 BLE MAC 聚合与 HID 多通道遥测
- **`src-tauri/src/win_battery.rs`**：新增 `SetupDiGetDeviceInstanceIdW` FFI、`extract_ble_mac` 及 `coalesce_bt_devices`，按 12 位 HEX BLE MAC 合并父子节点（例如将 `BTHLE\DEV_*` 的实时电量百分比精准合并至携带有 `VID&02258A_PID&0040` 的兄弟节点），彻底解决 `凌豹 K98PRO 5.0` 电量丢失。
- **`src-tauri/src/vendor_protocols.rs` + `src-tauri/src/telemetry_daemon.rs`**：
  - 按通道分离路径：`telemetry_path` / `vendor_control_path` / `led_path`；
  - 后台共享线程监听 `Inphic MI_02&COL03`（`UP=0x000A, U=0x0000`）被动 5 字节上报帧（经解耦的 `TelemetryCallback` 推送 `lumen-telemetry` 事件至前端，不污染 `--lib` 单元测试可执行文件的清单依赖）。

### 2.3 Windows 键盘软驱动引擎（`src-tauri/src/keyboard_engine.rs`）
- **纯 Win32 FFI (`WH_KEYBOARD_LL` + `SendInput`)**：使用 `KEYEVENTF_SCANCODE` 与 `LUMEN_EXTRA_INFO = 0x4C55_4D45` 防重入标识。
- **零侵入策略**：未开启软驱动、全局只读安全模式或当前层没有任何规则激活时自动卸载键盘钩子。
- **完整常用功能**：三层键位重映射（`base` / `fn1` / `game`）、组合键、多媒体键、SOCD 最后输入优先（Last-Input-Priority）急停、微动抖动抑制（保留长按连发不吞 Repeat）、Win 键锁定，以及独立异步 `macro_runner` 宏执行线程（支持 `once` / `repeat` / `while-held` / `toggle`）。
- **防卡死/紧急恢复兜底**：
  - `StuckKeyTracker` 切层/暂停/紧急停用/程序退出（`RunEvent::Exit`）时自动释放所有合成按下键；
  - 硬编码 `Ctrl + Alt + Esc` 紧急直通热键 + UI 一键“紧急停用键盘软驱动”；
  - 一键回滚历史配置快照。

## 4. 工程验证记录

1. **Rust 编译与单元测试 (`cargo test --manifest-path src-tauri/Cargo.toml`)**：
   - 覆盖 `safety`（`0x258A`/OTA/只读拦截与原子备份淘汰）、`win_battery`（BLE MAC 抽取与兄弟节点合并）、`vendor_protocols`（多通道分配与系统端点过滤）、`keyboard_engine`（键码映射、SOCD、防抖、卡键释放、紧急停用）、`thx_grpc`（Protobuf 编解码、X.509 v1/v3 SPKI 提取、回环校验与参数限幅）、`hecate_g5max`（状态与 `0xED` 灯效构造）、`inphic_in10`（64B `0x04` 帧校验和、DPI/LOD/7 档回报率/去抖编码、`0x09` 拦截与 `0x93` 门禁）。
2. **只读实机冒烟验证（全程零硬件写入）**：
   - `live_readonly_scan_smoke_test -- --ignored`：成功枚举 `Inphic IN10 (KP 8K)`、`凌豹 K98PRO 5.0`（BLE `19%`）、`凌豹 K98PRO (USB/2.4G)` 与 `漫步者 HECATE G5 Max 无线版`（`58%`, `HS 1.5.1 / DG 2.3.8`）。
   - `live_readonly_thx_grpc_check -- --ignored`：成功通过 X.509 v1 Pinned SPKI Verifier 连接本地 `localhost:49669`，读取 THX 服务版本 `4.2.35.1502` 及完整 `headphones` 17 项快照。
3. **前端与桌面构建门禁**：`npm.cmd run lint`、`npx.cmd tsx --test src/utils/deviceEngine.test.ts`、`npm.cmd run build`、`cargo check --release` 全量通过。
